أهلاً بيك في عنان

عشان التطبيق يشتغل مجانًا وبشكل شخصي بالكامل، هو بيستخدم مفتاح API مجاني من Google AI Studio بيكون بتاعك إنت. المفتاح بيتخزن على موبايلك بس، ومبيتبعتش لأي سيرفر غير سيرفر جوجل نفسه وقت المحادثة.

  1. افتح الموقع ده من المتصفح: aistudio.google.com/apikey
  2. سجّل دخول بحساب جوجل بتاعك.
  3. اضغط Create API key واختار أي مشروع أو خليه يعمل واحد جديد.
  4. انسخ المفتاح والصقه هنا تحت.

الطبقة المجانية في Gemini مش فترة تجريبية، بتفضل مجانية بحدود استخدام يومية كافية جدًا للاستخدام الشخصي.

لو حابب تتأكد إن المفتاح شغال، هنعمل طلب تجريبي واحد بعد الحفظ.
